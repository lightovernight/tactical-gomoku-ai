# 模型卡

## 基本信息

- 文件：`src/gomoku_ai/models/gomoku_25000.pt`
- 类型：五子棋Policy-Value残差网络
- 规则：15×15自由五子棋，无禁手，长连算胜
- checkpoint元数据：25,000局、250,000次梯度更新
- 参数量：326,403
- SHA-256：`7ce7a2f0ab8a9b49e2be0349041acce61c60cf732a0d1437996f7e40203e91da`

## 输入和输出

输入使用当前行动方视角的三个二值平面：己方棋子、对方棋子和空位。策略头
输出225个动作logits；价值头输出 `[-1, 1]` 范围内的当前行动方局面估值。

## 推理

模型由证明感知PUCT调用，而不是直接用策略头落子。发布默认配置为6400次
模拟和64个叶节点的推理batch。CUDA可用时自动使用GPU，否则使用CPU。

## 限制

本仓库不包含生成该checkpoint的训练器、数据集、replay buffer和完整实验
配置，因此模型训练过程不能仅由本仓库复现。模型仅针对当前自由五子棋规则；
在禁手规则、不同棋盘尺寸或不同胜利长度下不能直接使用。
