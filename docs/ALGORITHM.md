# 算法说明

## 总体结构

智能体由固定的策略价值网络、证明感知PUCT和一步战术求解器组成。网络对
当前行动方视角的棋盘进行评估：策略头产生全部225个落点的先验概率，价值头
估计当前行动方的胜负价值。

## 一步战术证明

每个首次到达的非终局搜索节点在网络推理前都会执行以下精确判断：

1. 当前行动方能够一步成五的动作被证明为 `+1`。
2. 对手只有一个一步成五点时，除封堵点之外的动作都被证明为 `-1`。
3. 对手存在至少两个不同的一步成五点时，当前行动方无法同时封堵，所有
   合法动作被证明为 `-1`；当前行动方自身能够立即获胜的动作仍为 `+1`。

如果存在已证明胜着，PUCT只在胜着中搜索；否则排除已证明败着。剩余策略
先验重新归一化。

## 证明传播

当一个叶节点或终局节点具有严格的 `+1/-1` 结果时，结果在父子视角之间
翻转并沿路径传播。一个节点只要存在已证明胜着即被证明为胜；只有全部合法
动作都被证明为败时才被证明为败。因此，一步求解器配合逐层传播可以在搜索
展开后建立多步强制胜负证明。

## 批量PUCT

默认搜索6400次，网络推理batch为64。一个批次先执行多次树遍历，并用虚拟
访问计数降低遍历集中到同一分支的概率；随后对不同叶节点去重、批量执行战术
证明，并只把仍未解决的节点送入神经网络。实际落子先应用证明过滤，再从访问
次数最大的动作中选择。
